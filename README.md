# PDFForge

Free, private, browser-based PDF editor built with Next.js 14.

All processing happens **client-side** — files never leave the user's device.

## Features

- Merge, Split, Compress, Rotate
- PDF ↔ Image, Word → PDF
- Watermark, Page Numbers, Sign, Edit / Annotate
- Protect / Unlock, Extract Text, Full Viewer

## Stack

Next.js 14 (App Router) · TypeScript · Tailwind CSS · pdf-lib · PDF.js · jsPDF · mammoth · Framer Motion

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```

## Privacy

Every tool runs in the browser with a 50MB per-file limit. No accounts. No server uploads.
